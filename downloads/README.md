# Installationspaket

**[ExitAI-Website-und-App.zip herunterladen](https://github.com/vieto1/ExitAI/raw/refs/heads/main/downloads/ExitAI-Website-und-App.zip)**

ZIP entpacken, Terminal im entpackten ExitAI-Ordner öffnen und nacheinander ausführen:

```bash
bash Setup.command
bash Start.command
```

Setup benötigt Internet und mehrere GB Speicher für die lokalen Laufzeiten und das Modell. Es ersetzt keine Systemsoftware. Die Anwendung wurde unter Linux geprüft; die macOS-Installation selbst ist noch ungetestet.

Die SHA-256-Prüfsumme steht in der benachbarten Datei. Dieser Ordner enthält die gebaute Auslieferung und wird beim erneuten Paketbau ausgeschlossen, damit das ZIP nicht sich selbst enthält. Quellcode und ausführliche Anleitung liegen im Hauptverzeichnis.
